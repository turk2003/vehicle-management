เริ่มที่ไฟล์นี้ แล้วซ้อมจาก [บทพูด Demo โค้ด และคำถาม](09-demo-code-and-rehearsal.md)

ข้อความสำหรับใช้ยืนยันรายละเอียดกับอาจารย์ด้วยตนเอง:

> ผมสอบโครงงาน 2 วันที่ 8 พฤศจิกายนครับ ขอสอบถามว่าต้องเตรียมเล่ม 3 หรือ 4 ชุด หรือตามจำนวนกรรมการ และ Demo แยกจากเวลานำเสนอ 15–20 นาทีใช่ไหมครับ รวมถึงคิวสอบกับห้องสอบของผมครับ

## 4. หลักฐานทางเทคนิคที่ตรวจในรอบนี้

ตรวจใน working tree วันที่ 31 ตุลาคม 2569:

| คำสั่ง | ผล |
|---|---|
| `npm test` | ผ่าน 161 tests จาก 29 ไฟล์ |
| `npm run lint` | ผ่าน ไม่มี error หรือ warning ที่รายงาน |
| `./node_modules/.bin/tsc --noEmit --incremental false` | ผ่าน exit code 0 |

ผลนี้ใหม่กว่าจำนวนในสไลด์วันที่ 24 ตุลาคมที่เป็น 142 tests และคู่มือเดิมที่เป็น 99 tests ให้ระบุวันที่กำกับเมื่อเปลี่ยนตัวเลขในสไลด์

รอบนี้ยังไม่ได้รัน production build, browser E2E, migration, seed หรือส่งคำขอไป SMTP/AI จริง และยังไม่ได้เปิด Demo กับฐานข้อมูลจริง จึงยังยืนยันความพร้อมของสิ่งเหล่านั้นไม่ได้

ประโยคใช้พูด:

> วันที่ 31 ตุลาคม ผมรันชุดทดสอบผ่าน 161 tests จาก 29 ไฟล์ ตรวจ TypeScript และ lint ผ่านครับ ผลนี้ครอบคลุมกรณีในชุดทดสอบ ส่วนการใช้งานผ่านหน้าจอและการเชื่อมต่อบริการจริง ผมเตรียมตรวจแยกตามรายการ Demo ครับ

ปรับประโยคสุดท้ายหลังตรวจ Demo จริงแล้ว โดยบอกเฉพาะสิ่งที่ทำสำเร็จและมีหลักฐาน
